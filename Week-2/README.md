# Week 2: Data Collection, Cleaning, and Preprocessing for Logistics Analysis

## Objective

This project focuses on the process of data collection, cleaning, and preprocessing for logistics analysis using Python.

## Tasks Performed

* Data collection simulation
* Data inspection and understanding
* Handling missing values
* Removing duplicate records
* Detecting and treating outliers
* Data normalization
* Correcting data types
* Standardizing inconsistent values

## Tools and Technologies

* Python
* Pandas
* NumPy
* Scikit-learn

## Project Outcome

The data preprocessing pipeline transforms raw logistics data into a clean, consistent, and analysis-ready dataset suitable for further analysis, visualization, and decision-making.
